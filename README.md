This is a quick&dirty tool to set the right time metadata to old audio and video files, and to move them into a hierarchical folder structure made of years and months.
The main goal is to have the files correctly placed on timelines.
Basically, it reads all the time-related info it can get from the file name and metadata and tries to determine which are the correct ones. If it cannot, it asks.
Once done, it rewrites all the file metadata and move the files to a target folder according to their reference year and month.
There are a couple extra things inside, but that's it.
If you need it, feel free to use it!
